# Realinov App

Proyecto migrado a Next.js manteniendo el diseño y la experiencia visual original.

## Comandos

- Instalar dependencias:

```
npm install
```

- Ejecutar servidor de desarrollo:

```
npm run dev
```

- Construir para producción:

```
npm run build
```

- Iniciar build de producción:

```
npm run start
```
